# Code of Conduct

This project exists to keep systems safe, and that starts with how we treat
each other. This code applies to everyone who takes part: in issues, pull
requests, reviews, discussions and any other project space, and whenever
someone represents the project in public.

## What we expect

- **Be respectful and patient.** Assume good faith. People bring different
  backgrounds, languages and levels of experience.
- **Critique the work, not the person.** Explain the *why* and link your
  sources.
- **Handle security responsibly.** Report vulnerabilities privately, as
  described in [SECURITY.md](SECURITY.md). Never post anyone's origin IP
  addresses, hostnames, certificates, credentials or other sensitive details
  in public.
- **Respect privacy and consent.** Share information about someone only with
  their permission.

## What is not acceptable

- Harassment, insults, threats, or personal or political attacks.
- Sexualised language or imagery, and unwelcome attention of any kind.
- Discrimination or exclusion based on any personal characteristic.
  Examples include age, body, disability, ethnicity, gender identity or
  expression, level of experience, nationality, appearance, race, religion,
  and sexual identity or orientation.
- Publishing other people's private information, including details of their
  infrastructure.
- Using this project to find, probe or attack systems that you don't operate
  or aren't authorized to test.
- Spam, trolling, or deliberately derailing a conversation.

## Reporting a problem

If you experience or witness unacceptable behaviour:

- Contact the maintainer, Nizar Chtioui
  ([@nizarchtioui](https://github.com/nizarchtioui)), privately, using the
  contact details on their GitHub profile.
- If the problem involves the maintainer, or you would rather not contact
  them, use GitHub's **Report content** option on the comment, issue or
  account, or contact GitHub Support.

Include links and a short description of what happened. Reports are handled
confidentially.

## Enforcement

The maintainer reviews every report. They may take any action they judge
appropriate, for example:

1. a private warning with an explanation
2. removing comments, commits or other contributions that break this code
3. a temporary ban from project spaces
4. a permanent ban

Retaliating against someone who reported a problem in good faith is itself a
violation of this code.
